QTrans — 找不到 Python 怎麼辦
================================================

QTrans 需要 Python 3.10 或更新的版本。

剛才的安裝程式找不到可用的 Python，可能是下面兩種情況之一。


情況一：還沒安裝 Python
------------------------------------------------

安裝程式已經幫你開啟下載頁面（python.org）。

請下載「Windows installer (64-bit)」，執行它，然後：

  ★ 務必勾選安裝畫面最下方的
    「Add python.exe to PATH」

這個選項預設是「沒有勾」的，而且很容易被忽略。
沒勾的話，之後每個指令都會找不到 Python。

勾好之後按「Install Now」就可以了。


情況二：已經裝過，但當初沒勾「Add to PATH」
------------------------------------------------

這是最常見的狀況。解法：

  1. 再執行一次當初的 Python 安裝檔
     （或從 python.org 重新下載同一個版本）
  2. 這次它會顯示「Modify / Repair / Uninstall」
  3. 選「Modify」
  4. 下一頁把「Add Python to environment variables」勾起來
  5. 按 Install

或者更簡單：直接從 python.org 裝一個新版本，
安裝時記得勾「Add python.exe to PATH」。


怎麼確認裝好了
------------------------------------------------

按 Win + R，輸入 cmd，按 Enter，然後輸入：

    python --version

看到「Python 3.13.x」之類的版本號就是成功了。

如果跳出 Microsoft Store 的安裝畫面，表示你碰到的是
Windows 內建的「假 python」—— 那不是真的 Python，
請照上面的步驟從 python.org 安裝。


裝好之後
------------------------------------------------

回到 D:\QTrans 資料夾，重新雙擊「安裝.bat」即可。


還是不行的話
------------------------------------------------

把 cmd 視窗裡的訊息複製給 Claude：

  在視窗標題列按右鍵 → 編輯 → 全選 → 再按一次 Enter
  （這樣就複製到剪貼簿了）

然後貼到對話裡，我來看是哪裡卡住。
