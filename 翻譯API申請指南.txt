QTrans — 翻譯 API 申請指南
==================================================

你現在遇到的狀況：
  ・Google 免金鑰版 → 429（學校共用 IP 被限流）
  ・Gemini → 503（模型過載）

兩者都是「供應商那邊的問題」，不是你的設定有錯。
最穩的解法是多準備一個不同供應商的備援，
QTrans 會在主引擎失敗時自動換過去。


==================================================
推薦順序（針對你的使用情境）
==================================================

第一順位　Gemini（你已經申請了）
  品質最好，長句、學術文字、專有名詞都明顯勝過其他家。
  缺點是免費方案的熱門模型常常 503。
  → 留著當主力，讓備援去處理它過載的時候。

第二順位　Groq（最建議補這一個）
  免費、速度極快，而且是「OpenAI 相容」端點，
  代表 QTrans 不用改程式就能用 —— 直接填在
  「OpenAI 相容端點」那一欄即可。
  重點是它跟 Google 是不同公司，Gemini 過載時它通常沒事。

第三順位　DeepL Free
  歐語品質公認最好，中英也很穩。每月 50 萬字元免費。
  申請時需要信用卡驗證（不會扣款），這是唯一的門檻。

保底　　　Google 免金鑰版
  不用申請，但在學校網路會一直 429。留著當最後手段。


==================================================
一、Groq（最建議，約 2 分鐘）
==================================================

1. 開啟 https://console.groq.com
2. 用 Google 帳號登入
3. 左側選單找「API Keys」→ Create API Key
4. 複製那串金鑰（只會顯示一次，請先貼到記事本）

5. 回到 QTrans：系統匣圖示右鍵 → 設定 → 翻譯引擎
   在「OpenAI 相容端點」區塊填：

     端點網址：https://api.groq.com/openai/v1
     API 金鑰：（剛才複製的那串）
     模型　　：見下方說明

6. 模型名稱要填目前有在線上的。到
   https://console.groq.com/docs/models
   看一下清單，挑一個「instruct」或「versatile」類的大模型。
   （Groq 的模型汰換很快，所以我不寫死在這裡，
     填錯的話 QTrans 會回報 HTTP 404 或模型不存在，換一個即可。）

7. 回「一般」分頁確認「自動改用其他可用引擎」有勾起來。
   這樣 Gemini 503 的時候就會自動換 Groq。

免費額度：約每分鐘 30 次請求，另有每日 token 上限。
翻譯這種短請求來說非常夠用。


==================================================
二、DeepL Free（約 5 分鐘，需信用卡驗證）
==================================================

1. 開啟 https://www.deepl.com/pro-api
2. 選「DeepL API Free」方案註冊
3. 需要填信用卡做身分驗證 —— 免費方案不會扣款，
   但這一步不能跳過。若不想給卡號就跳過 DeepL。
4. 註冊完成後到帳號頁面找「Authentication Key for DeepL API」
5. 填進 QTrans 的「DeepL」區塊，不要勾「使用 Pro 端點」

免費額度：每月 50 萬字元。
註：免費版金鑰結尾通常帶 ":fx"，複製時要整串帶走。


==================================================
三、OpenAI 官方（要付費，品質穩）
==================================================

1. https://platform.openai.com/api-keys
2. 需要先在 Billing 頁面儲值（最低額度不高，翻譯很省）
3. 建立金鑰後填進「OpenAI 相容端點」：

     端點網址：https://api.openai.com/v1
     API 金鑰：sk-...
     模型　　：gpt-4o-mini（便宜快速）或當時的同級型號

翻譯用量很小，實務上一個月通常花不到一杯飲料的錢。
但既然 Groq 免費就能用，這個可以之後再說。


==================================================
四、OpenRouter（一把金鑰用很多模型）
==================================================

1. https://openrouter.ai → 登入 → Keys → Create Key
2. 填進「OpenAI 相容端點」：

     端點網址：https://openrouter.ai/api/v1
     模型　　：到 https://openrouter.ai/models 挑，
               名稱結尾帶 ":free" 的是免費模型

免費模型每天約 50 次請求，適合試用或臨時備援。


==================================================
五、本機模型（完全免費、離線、資料不外流）
==================================================

如果你要翻譯的是學生資料、公文或任何不該外流的內容，
這是唯一真正安全的選項。

1. 到 https://ollama.com 下載安裝 Ollama
2. 開 cmd 執行（模型名稱請到 ollama.com/library 確認目前版本）：

     ollama pull qwen2.5:7b

   Qwen 系列對中文的支援比較好。
   7b 的模型約 5GB，需要 8GB 以上記憶體。

3. 填進 QTrans 的「OpenAI 相容端點」：

     端點網址：http://localhost:11434/v1
     API 金鑰：（留空）
     模型　　：qwen2.5:7b

優點：免費、離線、隱私。
缺點：翻譯品質不如 Gemini，而且吃電腦資源。


==================================================
六、LibreTranslate（開源，可自架）
==================================================

公開實例常常掛掉或限流，實務上建議自己架。
學校若有伺服器可以用 Docker 一行架起來：

  docker run -ti --rm -p 5000:5000 libretranslate/libretranslate

然後在 QTrans 填 http://那台機器的IP:5000

品質比不上前面幾個，但完全免費且資料不出校內網路。


==================================================
建議的最終配置
==================================================

  預設引擎：Gemini
  備援順序：Gemini → Groq → Google 免金鑰

這樣平常用品質最好的 Gemini，它過載時自動換 Groq，
Groq 也不行才退到 Google。你幾乎不會再看到錯誤畫面。

設定方式：
  設定 → 一般 → 勾「重試後仍失敗時，自動改用其他可用引擎」
  （預設就是開的）
