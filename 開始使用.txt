================================================================
  QTrans　跨程式即時翻譯工具
================================================================

  不管在 Word、PDF、瀏覽器還是 LINE，選一段文字按快速鍵，
  譯文立刻跳出來。不用切視窗、不用複製貼上。

  這是 QTranslate 的替代品。QTranslate 已經多年沒更新、
  常常壞掉，所以自己寫了一個。


----------------------------------------------------------------
  一、安裝
----------------------------------------------------------------

  你拿到的是哪一種？看資料夾裡有什麼：

  ● 有 QTrans.exe　→　免安裝版
    直接雙擊 QTrans.exe 就好，不用裝任何東西。
    （第一次執行 Windows 可能會跳出「不受保護的應用程式」警告，
      點「其他資訊」→「仍要執行」。這是因為程式沒有花錢買
      數位簽章，不是病毒。）

  ● 有 run.py 和「安裝.bat」　→　原始碼版
    1. 雙擊「安裝.bat」
    2. 如果跳出「找不到 Python」：
       它會自動開啟 Python 下載頁和一份說明。
       安裝 Python 時務必勾選最下面的
       「Add python.exe to PATH」，裝完再執行一次「安裝.bat」。
    3. 安裝完成後，雙擊「啟動 QTrans.bat」


----------------------------------------------------------------
  二、怎麼用
----------------------------------------------------------------

  程式啟動後會縮到右下角的系統匣（時鐘旁邊，可能要點「^」
  才看得到）。它不會一直佔著畫面。

  【選文字按 Ctrl + Q】

    在任何程式裡選一段文字，按 Ctrl + Q，
    譯文會在滑鼠旁邊跳出來。

    小視窗上還有：
      🔊 朗讀原文或譯文
      ⇄  交換語言方向
      下方圖示可以直接換翻譯引擎，不用進設定

  【Ctrl 連按兩下】

    不想記快速鍵的話，連按兩下 Ctrl 也會翻譯選取的文字。

  【選取即翻譯（進階）】

    在系統匣圖示上按右鍵 → 勾「選取即翻譯」，
    之後用滑鼠框選文字，放開滑鼠就自動翻譯，連按鍵都不用。

    這個功能會監聽滑鼠動作，有些防毒軟體會擋。
    若勾了沒反應，就用 Ctrl + Q，功能完全一樣。

  【主視窗】

    在系統匣圖示上點兩下，會打開主視窗，
    可以貼長文翻譯、查看翻譯紀錄。


----------------------------------------------------------------
  三、關於翻譯引擎與 API 金鑰
----------------------------------------------------------------

  ★ 不填任何金鑰也能用。★

  預設使用 Google 免費翻譯，裝好就能翻，不用申請任何東西。
  只是連續翻譯太多次（大約幾十次）可能會被暫時限流，
  等幾分鐘就會恢復。

  想要更快、更準、不限流，可以自己申請金鑰：

  ┌──────────────┬─────────┬──────────────────────────┐
  │ 引擎         │ 免費額度 │ 特色                     │
  ├──────────────┼─────────┼──────────────────────────┤
  │ Google 免費  │ 有限流   │ 預設，不用申請           │
  │ Groq         │ 很寬鬆   │ 最快（不到 1 秒），推薦  │
  │ DeepL        │ 50萬字/月│ 歐洲語言品質最好         │
  │ Gemini       │ 有免費層 │ 可以要求特定語氣         │
  │ LibreTranslate│ 自架免費│ 完全離線可用             │
  └──────────────┴─────────┴──────────────────────────┘

  申請步驟看同一個資料夾裡的「翻譯API申請指南.txt」。
  申請完在程式裡：系統匣圖示右鍵 → 設定 → 貼上金鑰。

  【重要】
  金鑰用 Windows 帳號加密後存在你自己的電腦裡
  （%APPDATA%\QTrans\config.json），不會跟著程式被複製走，
  也不會上傳到任何地方。換電腦要重新填一次。


----------------------------------------------------------------
  四、不能用的時候
----------------------------------------------------------------

  ● 按 Ctrl + Q 沒反應
    → 可能被其他程式搶走這組快速鍵。
      設定 → 熱鍵，改成 Ctrl + Shift + Q 之類的。

  ● 跳出「翻譯失敗」
    → 雙擊「檢查引擎.bat」，它會逐一測試每個引擎並列出原因。
      （免安裝版沒有這個檔案，請改在設定裡換一個引擎試試。）

  ● 「選取即翻譯」勾了沒用
    → 防毒軟體擋掉滑鼠監聽。用 Ctrl + Q 即可，功能一樣。

  ● 其他問題
    → 問給你這個程式的人。
